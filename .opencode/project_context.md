# ERP Inventory System

## Tech stack

- Backend: Laravel 12
- Database: PostgreSQL
- Mobile: Kotlin + Jetpack Compose
- Guest ordering: Blade
- Deployment: VPS

## Business domain

Food and beverage (make-to-order).

## Main modules

- Customer management
- Product management
- Inventory management
- Order management
- Production management
- Payment management

## Important rules

- Never modify migrations.
- Never rename columns.
- Never delete existing code.
- Follow REST conventions.
- Use Form Requests.
- Use API Resources.
- Keep controllers thin.
