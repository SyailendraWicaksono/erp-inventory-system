# Rules

- Read the docs folder before making changes.
- Never change migrations without permission.
- Never delete existing code.
- Never rename database tables.
- Never rename database columns.
- Follow Laravel 12 conventions.
- Use PostgreSQL.
- Use Eloquent ORM.
- Use Form Requests.
- Use API Resources.
- Use Service classes.
- Keep controllers thin.
- Explain every change before applying it.
- Ask before creating new dependencies.

## Git rules

- Commit after every completed feature.
- Never push unreviewed code.
- Never delete existing code without permission.

## Laravel rules

- Use controllers.
- Use form requests.
- Use resources.
- Use service classes.
- Use dependency injection.
- Follow PSR-12.
